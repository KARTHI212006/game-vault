# Calculator (GameVault)

Open this calculator in your browser via XAMPP. Copy the `calculator` folder into your web root (already placed under `gamevault/calculator`).

URL:

http://localhost/gamevault/calculator/

Features:
- Basic arithmetic (+ - * /)
- Decimal support and parentheses
- Keyboard support (numbers, + - * /, Enter, Backspace, Esc)

Notes:
- Evaluation is done client-side. Avoid entering untrusted code in production.
